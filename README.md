# Холодильник

Веб-приложение для учёта продуктов дома и ведения списков покупок. Работает без
авторизации, backend и внешних API. Интерфейс на русском языке, mobile-first,
светлая тема.

Сейчас это каркас: нижняя навигация с вкладками «Остатки» (`/`) и «Покупки»
(`/shopping`), кнопка «Настройки» в шапке и отдельный экран настроек
(`/settings`). Разделы пока показывают заглушки.

## Технологии

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS
- lucide-react для иконок

## Запуск

Нужен [Bun](https://bun.sh) (либо Node.js 24+).

```bash
bun install
bun run dev
```

Приложение откроется на http://localhost:3000.

Продакшен-сборка:

```bash
bun run build
bun run start
```

## Скрипты

| Команда           | Назначение                       |
| ----------------- | -------------------------------- |
| `bun run dev`     | Запуск в режиме разработки       |
| `bun run build`   | Продакшен-сборка                 |
| `bun run start`   | Запуск собранного приложения     |
| `bun run check`   | Линт + проверка типов + сборка   |
| `bun run format`  | Форматирование кода (Prettier)   |

## Структура

- `src/app/(tabs)` — разделы с нижней навигацией: «Остатки» (`/`) и «Покупки» (`/shopping`)
- `src/app/settings` — экран «Настройки»
- `src/components` — общие компоненты: шапка (`app-header`), нижняя навигация
  (`bottom-nav`), заглушка пустого списка (`empty-state`)
