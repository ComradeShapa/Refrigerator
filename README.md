# Холодильник

Веб-приложение для учёта продуктов дома и ведения списков покупок. Работает без
авторизации, backend и внешних API. Интерфейс на русском языке, mobile-first,
светлая тема.

Сейчас реализованы: нижняя навигация с вкладками «Остатки» (`/`) и «Покупки»
(`/shopping`), кнопка «Настройки» в шапке, экран настроек (`/settings`) и слой
хранения данных в браузере. На экране «Остатки» выводится каталог из 15 базовых
продуктов, «Покупки» пока заглушка.

## Технологии

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS
- lucide-react для иконок

## Запуск

Нужен [Bun](https://bun.sh) (либо Node.js 24+).

```bash
bun install
bun run dev
```

Приложение откроется на http://localhost:3000.

Продакшен-сборка:

```bash
bun run build
bun run start
```

## Модель данных

Типы описаны в `src/lib/types.ts`.

### Продукт — `Product`

| Поле                     | Тип                                  | Описание                                        |
| ------------------------ | ------------------------------------ | ----------------------------------------------- |
| `id`                     | `string`                             | Идентификатор                                   |
| `name`                   | `string`                             | Название, например «Молоко»                     |
| `unit`                   | `"шт" \| "г" \| "кг" \| "мл" \| "л"` | Единица измерения                               |
| `stock`                  | `number`                             | Текущий остаток, при создании — `0`             |
| `dailyRate`              | `number \| null`                     | Среднесуточный расход; `null` — не задан        |
| `category`               | `string`                             | Категория, например «Овощи»                     |
| `createdAt`, `updatedAt` | `string`                             | Даты создания и обновления, ISO                 |

### Список покупок — `ShoppingList`

`id`, `name`, `createdAt`, `updatedAt`.

### Пункт списка покупок — `ShoppingListItem`

`id`, `listId` (ссылка на список), `name`, `quantity` (`null` — не указано),
`unit`, `checked` (куплено), `createdAt`, `updatedAt`.

### Настройки — `AppSettings`

`theme: "light" | "dark" | "system"`, по умолчанию `"light"`.

## Хранение данных

Данные хранятся в `localStorage` браузера и читаются только через модуль
`src/lib/storage.ts`. Все функции модуля асинхронные (возвращают `Promise`),
хотя внутри пока `localStorage`, — при переходе на backend экраны менять не
придётся.

| Функции                                              | Данные               |
| ---------------------------------------------------- | -------------------- |
| `loadProducts` / `saveProducts`                      | продукты             |
| `loadShoppingLists` / `saveShoppingLists`            | списки покупок       |
| `loadShoppingListItems` / `saveShoppingListItems`    | пункты списков       |
| `loadSettings` / `saveSettings`                      | настройки            |

Ключи: `fridge.products.v1`, `fridge.shopping-lists.v1`,
`fridge.shopping-list-items.v1`, `fridge.settings.v1`.

Принятые решения:

- **Первый запуск.** Если продуктов в хранилище нет, модуль создаёт каталог из
  15 базовых продуктов — молоко, хлеб, яйца, сыр, курица, рис, макароны,
  картофель, лук, морковь, яблоки, бананы, масло, соль, сахар — с нулевым
  остатком и не заданным расходом. Пустой список (`[]`) первым запуском не
  считается, поэтому удалённые вручную продукты не возвращаются после
  перезагрузки страницы.
- **Повреждённые данные.** Ошибки парсинга JSON обрабатываются безопасно:
  значение трактуется как отсутствие данных, в консоль пишется ошибка,
  подставляются значения по умолчанию (для продуктов — заново создаётся
  каталог). Записи с некорректными полями отбрасываются.
- **Ошибки записи** (недоступный `localStorage`, переполнение квоты) не
  подавляются: функции сохранения пробрасывают исключение, а экран решает, как
  сообщить о проблеме.
- **Идентификаторы** базового каталога фиксированные (`milk`, `bread`, …),
  чтобы сид был стабильным между запусками.

## Структура

- `src/app/(tabs)` — разделы с нижней навигацией: «Остатки» (`/`) и «Покупки» (`/shopping`)
- `src/app/settings` — экран «Настройки»
- `src/components` — общие компоненты: шапка (`app-header`), нижняя навигация
  (`bottom-nav`), списки экранов (`product-stock-list`, `settings-list`),
  заглушка пустого списка (`empty-state`)
- `src/lib/types.ts` — типы модели данных
- `src/lib/catalog.ts` — базовый каталог продуктов для первого запуска
- `src/lib/storage.ts` — асинхронное хранилище поверх localStorage
